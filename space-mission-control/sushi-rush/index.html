SUSHI CHEF ACADEMY

Learn how multiplication helps you prepare sushi orders quickly and accurately!

🍣 1. EQUAL GROUPS
Multiplication happens when groups have the EXACT SAME NUMBER of items.
Example: 3 plates with 4 sushi pieces each is 3 equal groups of 4.
➕ 2. REPEATED ADDITION
Instead of counting one by one, add the groups together:
4 + 4 + 4 = 12.
In multiplication, this is written as: 3 × 4 = 12!
🍱 3. HOW TO COOK IN SUSHI RUSH
1. Select Ingredient (Salmon, Tuna, Avocado, etc.)
2. Roll & Slice on the bamboo mat
3. Add pieces to each plate using the +1, +2, +3 buttons
4. Check the math formula: [Plates] × [Pieces] = [Total]
5. Click SERVE ORDER to delight your customer!
